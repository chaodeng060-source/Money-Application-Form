# 购物申请单 · Money-Application-Form

一点人机互动小道具。

想买东西，先写一张申请单递给你的 AI，让它帮你想想该不该买。可以一位 AI 说了算，也可以几位 AI 一起投票。

就一个网页文件：不用装、不用注册，没有服务器也没有广告。单子只存在你自己的浏览器里。

**在线用**：<https://chaodeng060-source.github.io/Money-Application-Form/>

## 怎么用

1. 在「我的审批人」里写上你家 AI 的名字，可以加好几位。
2. 写好想买什么、多少钱、为什么、急不急，选谁来审，递出去。
3. 点审批人旁边的「复制申请」，把那段文字发给那位 AI。
4. 它回完，把整段回复贴回来点「识别」，结论会自动盖到单子上。它没按格式写也没关系，看完回复自己点「批准 / 有条件批准 / 驳回」。

几位一起审的时候挨个发。后面的人复制到的申请里，会带上前面已经投了的票，可以参考，也可以投不一样的。

## 审批规则

只有一位审批人时，它说了算。几位一起审时选一种：

| 规则 | 怎么算 |
|---|---|
| 多数通过 | 过半同意就批，过半驳回就驳；票投完还打平，算驳回 |
| 全票通过 | 每一位都同意才批，有一位驳回就驳 |
| 权重 | 每位 1–3 票，赞成票数过半就批，其余同多数通过 |

「有条件批准」算赞成票。只要有一位附了条件，通过时盖的章就是「有条件批准」。

## 审批标记

复制给 AI 的申请末尾，会教它在回复最后写一行：

```
[[审批:p261023-ab12:批准|一句批语]]
```

结论写「批准 / 有条件 / 驳回」都认，也认 approve / conditional / reject；全角冒号、全角竖线也行。批语 40 字以内。

## 数据

- 单子存在浏览器的 localStorage 里，不上传任何地方。
- 换手机、清浏览器缓存之前，用页面底部的「导出备份」存一个 JSON 文件，到新地方再「导入备份」。
- 在微信里打开的话，缓存可能会被微信清掉，导出也可能用不了。常用的话，建议用手机浏览器打开，或者添加到主屏幕。

## 自己部署

只有 `index.html` 一个文件。下载下来用浏览器打开就能用，也可以放到任何静态托管上（GitHub Pages、Vercel、自己的服务器）。
